반갑습니다! API를 엮어서 하나의 완성된 서비스를 만드는 아주 멋진 미션을 맡으셨군요. 이 미션의 핵심은 **"LLM의 출력을 프로그래밍적으로 다룰 수 있는 구조(JSON)로 만드는 것"**과 **"데이터를 조합해 사용자 친화적인 결과물(Markdown)을 만드는 것"**입니다.

성공적인 미션 수행을 위해 LLM에게 내릴 **두 가지 핵심 프롬프트**를 설계해 드립니다.

---

### 1. 1차 추천 생성을 위한 프롬프트 (JSON 추출용)

이 단계에서는 LLM이 단순히 답변하는 것이 아니라, 파이썬 코드가 읽을 수 있는 **JSON 형식**으로만 답하게 하는 것이 중요합니다.

**[프롬프트 예시]**

리드미가 내과제고 이걸 코드가 정확하게 들어갔는지 알고싶어
내용을 분석해서 오류 부분을 수정해 줘.


> **역할:** 너는 한국 국내 여행 전문가야.
> **작업:** 사용자가 입력한 날짜에 가장 여행하기 좋은 국내 도시 하나를 추천해줘.
> **입력 날짜:** `{user_date}`
> 
> **출력 형식:** 반드시 아래의 JSON 구조로만 응답해줘. 다른 설명은 생략해.
> ```json
> {
>   "recommended_city": "도시이름",
>   "weather": "날씨 요약",
>   "events": ["행사1", "행사2"],
>   "reason": "추천 근거(2~4문장)"
> }
> ```
> **주의사항:** 
> 1. `recommended_city`는 지도 API에서 검색 가능하도록 '제주', '강릉', '부산'처럼 명확한 도시 이름이어야 함.
> 2. 반드시 유효한 JSON 형식이어야 함.

---

### 2. 최종 여행 리포트 생성을 위한 프롬프트 (Markdown 생성용)

지도 API를 통해 가져온 맛집 정보와 1차 추천 정보를 합쳐서 사용자에게 보여줄 예쁜 리포트를 만드는 단계입니다.

**[프롬프트 예시]**
> **역할:** 너는 전문 여행 가이드이자 작가야.
> **작업:** 제공된 여행 정보와 맛집 데이터를 바탕으로 매력적인 '국내 여행 추천 리포트'를 Markdown 형식으로 작성해줘.
> 
> **제공된 데이터:**
> 1. 기본 정보: `{first_recommendation_json}`
> 2. 맛집 리스트: `{restaurant_list_data}`
> 
> **리포트 포함 항목:**
> - # `{user_date}` 국내 여행 추천 리포트 (제목)
> - ## 추천 지역 및 이유
> - ## 날씨 및 현지 분위기
> - ## 주요 행사 및 축제
> - ## 추천 맛집 (맛집 데이터가 없으면 "데이터 없음"이라고 표기)
> - ## 추천 1일 일정 (오전/오후/저녁으로 나누어 제안)
> - ## 가이드 한마디
> 
> **작성 스타일:** 친절하고 설레는 말투로 작성해줘.

### 💡 학습 도우미의 추가 팁 (구현 시 참고하세요!)

1.  **JSON 파싱 에러 처리:**
    LLM이 가끔 JSON 앞뒤에 ```json ... ``` 같은 마크다운 태그를 붙일 때가 있습니다. 파이썬에서 `json.loads()`를 하기 전에 이 태그들을 제거하거나, 프롬프트에 "순수 JSON만 출력해달라"고 강조하는 것이 좋습니다.

2.  **맛집 데이터 전달:**
    지도 API(카카오/네이버)에서 받은 원본 JSON을 그대로 LLM에게 던지면 토큰을 많이 소비합니다. 필요한 정보(`name`, `address`, `category`)만 추출해서 리스트 형태로 정리한 뒤 2번째 프롬프트에 넣어주세요.

3.  **에러 핸들링:**
    미션 요구사항에 있는 것처럼, 지도 API가 실패하더라도 프로그램이 멈추지 않게 `try-except`로 감싸고, 맛집 리스트 변수에 빈 리스트 `[]`를 할당하여 리포트 생성 단계로 넘어가도록 설계하세요.

4.  **보안:**
    `.env` 파일을 만들고 `python-dotenv` 라이브러리를 사용해 보세요. 
    ```python
    import os
    from dotenv import load_dotenv
    load_dotenv()
    api_key = os.getenv("OPENAI_API_KEY")
    ```
    이렇게 하면 코드를 공유해도 내 소중한 API 키가 유출되지 않습니다!

이 프롬프트들을 활용해서 멋진 여행 플래너를 완성해 보세요! 하시다가 막히는 코드가 생기면 언제든 다시 물어봐 주세요. 화이팅입니다! 





API를 호출하는 것을 넘어 **"데이터의 흐름(LLM → JSON → 지도 API → LLM → Markdown)"**을 설계하는 것이 핵심


미션 내용이 아주 알차고 흥미롭네요! 단순히 API를 호출하는 것을 넘어 **"데이터의 흐름(LLM → JSON → 지도 API → LLM → Markdown)"**을 설계하는 것이 핵심입니다.

미션 수행을 위해 준비해야 할 것들을 **단계별**로 정리해 드릴게요.

---

### 1단계: API 키 발급 (가장 먼저 해야 할 일)

두 가지 종류의 API 키가 필요합니다.

1.  **LLM API (택 1)**
    *   **OpenAI API:** [platform.openai.com](https://platform.openai.com/)에서 가입 및 키 발급 (유료 결제 필요할 수 있음)
    *   **Google Gemini API:** [Google AI Studio](https://aistudio.google.com/)에서 발급 (**무료**로 시작하기 좋음)
2.  **지도/장소 검색 API (택 1)**
    *   **Kakao Developers:** [카카오 개발자 센터](https://developers.kakao.com/)에서 '내 애플리케이션' 등록 후 **REST API 키** 발급
    *   **Naver Developers:** [네이버 개발자 센터](https://developers.naver.com/)에서 '애플리케이션 등록' 후 **Client ID/Secret** 발급

---

### 2단계: 개발 환경 및 라이브러리 설치

파이썬 3.10 이상 환경에서 아래 라이브러리들을 설치해야 합니다.

```bash
# API 호출을 위한 라이브러리
pip install requests 

# 환경변수 관리를 위한 라이브러리
pip install python-dotenv

# 선택한 LLM에 따른 라이브러리 (하나만 설치해도 됨)
pip install openai
pip install google-generativeai
```

---

### 3단계: 프로젝트 구조 잡기

폴더와 파일을 미리 만들어 두면 코딩이 훨씬 수월합니다.

*   `main.py`: 전체 로직 실행 파일 (argparse 포함)
*   `.env`: API 키 저장 (보안)
*   `.gitignore`: `.env`와 `results/`를 GitHub에 올리지 않도록 설정
*   `results/`: 결과 파일이 저장될 폴더 (코드에서 자동으로 생성하게 만들어야 함)

---

### 4단계: 핵심 로직 설계 (미션의 흐름)

코드를 짜기 전에 이 순서를 머릿속에 그려보세요.

1.  **입력 받기:** `argparse`로 `-date` 인자 받기 + 날짜 형식(`YYYY-MM-DD`) 검증
2.  **1차 LLM 호출:** 
    *   "이 날짜에 가기 좋은 국내 도시 하나를 JSON 형식으로 추천해 줘"라고 프롬프트 작성
    *   결과를 `json.loads()`로 파싱해서 `recommended_city` 추출
3.  **지도 API 호출:** 
    *   추출한 `recommended_city`를 검색어로 맛집 검색
    *   결과가 없어도 에러로 멈추지 않게 `try-except` 처리
4.  **2차 LLM 호출:**
    *   1차 결과 + 맛집 리스트를 합쳐서 "이걸로 멋진 Markdown 리포트를 써줘"라고 요청
5.  **파일 저장:** 
    *   `results/` 폴더에 JSON과 MD 파일 저장

---

### 5단계: 주의 사항 (미션 합격 포인트)

*   **JSON 파싱 에러 대응:** LLM이 가끔 JSON 형식을 틀릴 수 있습니다. 이때 `try-except`로 잡아서 **딱 한 번만 다시 시도**하는 로직을 넣어보세요.
*   **보안:** 코드 안에 `api_key = "sk-..."`라고 절대 쓰지 마세요. 반드시 `os.getenv()`를 사용하세요.
*   **사용자 안내:** API 키가 설정 안 되어 있으면 "`.env 파일을 확인하세요`"라고 친절하게 알려줘야 합니다.
